Advanced Analytics & Statistical Modeling
TimeLine : 11 Days
A
Objective: Apply statistical analysis, time series forecasting, customer segmentation, and basic predictive modeling.
Activities
  1. 1. Day 28-30: Statistical Analysis
    • Descriptive statistics (mean, median, mode, variance, standard deviation, skewness, kurtosis)
    • Inferential statistics:
      • Confidence intervals
      • Hypothesis testing (t-test, chi-square test, ANOVA)
      • p-values and significance levels
    • Correlation vs causation analysis
    • Use scipy.stats for statistical tests
    • Document findings with business implications

  1. 2. Day 31-33: Time Series Analysis
    • Convert data to time series format (set datetime index)
    • Resample data (daily, weekly, monthly)
    • Decompose time series: trend, seasonality, residuals (using statsmodels)
    • Check stationarity (ADF test)
    • Apply smoothing techniques: moving average, exponential smoothing
    • Build basic forecasting: ARIMA / SARIMA model
    • Evaluate forecast accuracy (MAE, RMSE, MAPE)

  1. 4. Day 37-38: Predictive Modeling (Basic)
    • Define target variable (churn, sales, etc.)
    • Split data into train/test sets
    • Build models:
      • Linear Regression (for numeric prediction)
      • Logistic Regression (for classification)
      • Decision Tree (for interpretability)
    • Evaluate models: R², MAE, RMSE (regression) / Accuracy, Precision, Recall, F1-Score, ROC-AUC (classification)
    • Feature importance analysis
    • Document model limitations
